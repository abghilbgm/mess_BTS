Host this page for free on GitHub Pages in 3 simple steps:

  1. Create a free account on GitHub.com.
  2. Create a new public repository named meal-counter.
  3. Upload these project files (index.html, style.css, app.js) directly to the repository and enable GitHub Pages under Settings -> Pages.

Your private meal counter will be live at:
https://<your-username>.github.io/meal-counter

Quick Instructions

1

Open Poll in WhatsApp

Find the meal poll in your WhatsApp Group Chat. Click "View votes" or "Poll details".

2

Copy Voter Data

On WhatsApp Web, select/highlight all text inside the vote details side panel (or press Cmd+A / Ctrl+A inside the panel) and copy it.

3

Paste & Match

Paste the copied text in the input tab and click Analyze. Define which options represent Breakfast, Lunch (Veg/Non-Veg), or Dinner (Veg/Non-Veg).

💡

Mobile Tip

To use mobile data, click "Export Chat" (without media) inside WhatsApp settings, upload the _chat.txt file to the Upload Chat Export tab, and we'll extract the votes automatically.
